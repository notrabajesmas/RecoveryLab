# Validation Cycle 001 — Can a person recover a file?

**Date**: In progress (pre-validation complete)
**RecoveryLab version**: v0.6.1
**Participants**: 10 external users (never saw the project before)

This is not an experiment. It is a validation cycle.
We are validating a concrete product hypothesis:
> A person without experience can install RecoveryLab, run demo, and recover files without help.

---

## Pre-condition: Clean install test

Before running UXR-001 with external testers, the author must verify
installation from a completely clean machine:

- Not the development machine
- Not a machine with Python already configured
- Not a machine with the repo cloned
- Ideally: a fresh VM, another PC, or a friend's computer

Follow **only** the README. If at any point you need to do something
the README doesn't say, that's a bug in the README — fix it first.

---

## Mission given to each participant

Do NOT say "probá RecoveryLab." That introduces pleasing bias.

Say:

> "Necesito que recuperes los archivos de esta imagen NTFS.
> No puedo responder preguntas.
> Todo lo necesario debería estar en el README."

The mission is real. The silence is intentional.

---

## Moderator rule

The moderator can only say one phrase:

> *"Do what you would do if I wasn't here."*

Nothing else. Not "look at the README." Not "try demo first."
Even a hint alters the measurement.

## Real disk case (2026-08-10)

During validation, the author tested RecoveryLab against a real damaged disk:

- **Disk**: TOSHIBA MK5065GSX 500GB USB (PHYSICALDRIVE2)
- **Status**: Online in DiskPart, but Windows sees filesystem as RAW
- **Structure**: GPT, 2 partitions (15 MB MSR + 465 GB Basic Data)
- **Partition 2 offset**: 16,777,216 bytes (16 MB)
- **Partition type GUID**: ebd0a0a2-b9e5-4433-87c0-68b6b72699c7 (Basic Data)
- **Problem**: NTFS structures damaged — boot sector or MFT corrupt
- **Next step**: Read boot sector with diag_boot.py (512 bytes, read-only)
- **Blocker**: Only 97.5 GB free space combined — cannot create full 465 GB image
- **Imaging**: Need external storage ≥500 GB or FTK Imager

This is the first real NTFS recovery case for RecoveryLab.
If recovery succeeds, it validates the engine against real-world damage.

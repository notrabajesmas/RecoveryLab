# Installation

## Requirements

- Python 3.10 or later
- Linux, macOS, or Windows

## Install from source

```bash
git clone https://github.com/notrabajesmas/RecoveryLab.git
cd RecoveryLab
pip install -e .
```

This installs the `recoverylab` command globally.

## Verify installation

```bash
recoverylab --version
# v0.5.2
```

## Without installation

You can also run directly:

```bash
cd RecoveryLab
python recoverylab.py --version
```

## Dependencies

RecoveryLab uses only Python standard library modules. No external dependencies required.
